# Developer Portfolio

A responsive personal portfolio website showcasing my web development projects, technical skill stack, and relevant experience.

🚀 **Live Demo:** [View Live Portfolio](https://Chukwu-Emmanuel-Eke.github.io/portfolio/)

---

## 🛠️ Built With

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling & Layout:** Modern CSS Flexbox, Grid, Responsive Web Design
- **Tools & Hosting:** Git, GitHub Pages, VS Code

---

## ⚡ Features

- **Responsive Design:** Fully optimized for desktop, tablet, and mobile screens.
- **Interactive UI:** Smooth navigation, clean transitions, and dynamic user interface elements.
- **Project Showcase:** Highlights real-world applications with live demos and repository links.
- **Contact Integration:** Direct access to reach out for collaborations or direct inquiries.
